# @stack/app

Tauri v2 desktop application shell for the Stack project.

## Features

- **Tauri v2**: Latest version of the Tauri framework.
- **Rust**: High-performance backend logic.
- **Security**: Configured capabilities and permissions.
- **Cross-Platform**: Builds for macOS, Windows, and Linux.

## Getting Started

### Prerequisites

- Rust (latest stable)
- Node.js (v22+)
- pnpm (v10+)

### Installation

```bash
pnpm install
```

### Development

Start the Tauri development window (requires `@stack/web` dev server):

```bash
pnpm tauri dev
```

### Building

Build the application for distribution:

```bash
pnpm tauri build
```
