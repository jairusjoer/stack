# @stack/web

Frontend application for the Stack project, built with Vue 3, TypeScript, and Vite.

## Features

- **Vue 3**: Composition API with `<script setup>`.
- **TypeScript**: Static type checking.
- **Vite**: Fast development server and bundler.
- **Swagger UI**: API documentation integration.

## Getting Started

### Prerequisites

- Node.js (v22+)
- pnpm (v10+)

### Installation

```bash
pnpm install
```

### Development

Start the web development server:

```bash
pnpm dev
```

### Building

Build the web application:

```bash
pnpm build
```
